1. Quel est le rôle d'un serveur web ?

Le serveur web (Apache ici) parle HTTP avec les navigateurs. La réception des fichiers, c'est le travail du serveur FTP.

2. Quel est le rôle d'un serveur FTP ?

FTP = File Transfer Protocol : un protocole de transfert de fichiers, indépendant du Web.

3. Dans http://web-mmi2.iutbeziers.fr/~jean.dupont/, quel est le nom d'hôte ?

On enlève le protocole et tout ce qui suit le premier « / ».

4. Pour déposer des fichiers sur web-mmi2 depuis mon poste, il me faut…

Schéma client-serveur : c'est le client qui sollicite le serveur.

5. Où l'utilisateur jean.dupont doit-il placer ses pages HTML ?

Seul le contenu de public_html est publié par le serveur web, à l'adresse /~jean.dupont/.

6. Quel est le port par défaut du protocole FTP ?

21 pour FTP, 22 pour SFTP, 80 pour HTTP, 443 pour HTTPS.

7. Je visite mon URL et j'obtiens « Index of /~login » avec seulement « Parent Directory ». Cela signifie…

Sans index.html, Apache affiche la liste du contenu du dossier, ici vide.

8. J'ai déposé Accueil.HTML dans public_html, mais mon URL affiche toujours « Index of ». Pourquoi ?

La page d'accueil doit s'appeler index.html, en minuscules.
