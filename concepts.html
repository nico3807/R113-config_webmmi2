Avant de manipuler

Client, serveur, HTTP et FTP

Mettre un site en ligne fait intervenir deux services indépendants qui tournent sur la même machine : l'un sert à déposer les fichiers, l'autre à les afficher.

Le schéma client-serveur, en mouvement

La communication suit un schéma logique client-serveur : il faut qu'un client sollicite un serveur pour que ce dernier lui réponde. Lance les deux animations et observe quel client parle à quel serveur.

À retenir

FTP (File Transfer Protocol) est un protocole de transfert de fichiers. C'est un service qui tourne en totale indépendance du Web : ils ne sont pas liés. Ils partagent seulement le même disque.

Anatomie de ton URL

Clique sur chaque partie de l'adresse de ton espace web pour comprendre son rôle.

http://web-mmi2.iutbeziers.fr/~/

À partir de l'URL, il est facile de trouver le nom de la machine hébergeant le serveur Web : il suffit d'enlever le protocole, http://, et tout ce qui est après le premier / (en incluant le /).
