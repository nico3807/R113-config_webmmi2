Dépannage : que vois-tu ?

Not Found (404)
  • public_html n'existe pas, est mal nommé ou n'est pas directement dans ton espace personnel.
  • Le login dans l'URL est faux, ou il manque le ~.
  • Pour une page précise : le nom du fichier ne correspond pas exactement (majuscules, extension).
Index of /~login

public_html est bien en place mais il n'y a pas de fichier index.html à sa racine. Renomme ta page d'accueil ou vérifie qu'elle n'est pas restée dans un sous-dossier.

Forbidden (403)

Les droits sont trop restrictifs. Dans le client FTP : clic droit > Droits d'accès au fichier. 755 pour les dossiers, 644 pour les fichiers.

La page s'affiche sans style ni images
  • Les dossiers css/ ou img/ n'ont pas été envoyés.
  • Chemins absolus vers ton disque (C:\..., file://) : utilise des chemins relatifs.
  • Différence de majuscules entre le nom du fichier et le lien.
  • Ancienne version en cache : recharge avec Ctrl + F5.
Le client FTP ne se connecte pas
  • Vérifie l'hôte : web-mmi2.iutbeziers.fr, sans http:// ni chemin.
  • Vérifie le couple protocole / port : FTP + 21, ou SFTP + 22.
  • Login IUT, pas l'adresse mail ; attention au verrouillage majuscules pour le mot de passe.

Mettre à jour son site

  1. Modifier les fichiers sur son poste et les tester localement.
  2. Se connecter avec le client FTP, ouvrir public_html côté distant.
  3. Envoyer les fichiers modifiés et accepter d'écraser les anciens.
  4. Recharger la page dans le navigateur (Ctrl + F5).
